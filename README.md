# Vow Buddy — Shopify theme

Backup of the live theme for vowbuddy.com, pulled straight from Shopify.

- **Theme:** "Vow Buddy v5" (based on Horizon)
- **Pulled:** 31 October 2026
- The custom parts are `sections/vb-landing.liquid`, `sections/vb-page.liquid` and `assets/vb-global.css` (the "linen and ink" look: Fraunces + Figtree, bottle green, gold accents).
- `pages/` holds the HTML body of each Shopify page (Online Store > Pages), one file per page. These are not theme files.
- Everything else is the theme exactly as it sits in Online Store > Themes.

The planner app itself (plan.vowbuddy.com) lives in the separate `vowbuddy` repo.
